# 🌊 Visit Jeddah
### Discover the City Where Culture Meets the Red Sea

**Visit Jeddah** is a multi-page tourism website designed to showcase the beauty, culture, and experiences of Jeddah, Saudi Arabia.

The project offers a visually engaging way to explore the city's iconic landmarks, historical attractions, cultural destinations, and entertainment experiences.

## ✨ Features

- **Explore Jeddah:** Discover tourist attractions and experiences across the city.
- **Destination Pages:** Dedicated pages highlighting individual landmarks and attractions.
- **Interactive Navigation:** Navigate between the homepage, exploration page, and destination pages.
- **Visual Experience:** Images, video, and styled content designed to showcase the city's identity.
- **Newsletter Interface:** An email subscription form with input validation and interactive feedback.

## 🚀 Getting Started

No additional frameworks or installation are required.

**1. Clone the repository**

```bash
git clone https://github.com/ZuhrahAsAStudentInUQU/visit-jeddah.git
```

**2. Navigate to the project**

```bash
cd visit-jeddah
```

**3. Run the website**

Open `VisitJeddah.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
